# **Chumbi**
A Chump package designed for the creation of ambisonic architectures in ChucK. Meant for encoding, decoding and altering B-Format ambisonic signals, but misuse is always welcome.

*To install this package, type in terminal:*
```txt
  chump install Chumbi
```
